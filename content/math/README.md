# Математика — Svitlo textbook package

`@svitlo/math` is a platform-neutral, compiled ESM textbook package. It does not own Next.js routes or host navigation. `content/playground` defines the canonical package architecture; this package publishes **only** its actual authored content.

## Authoring

The existing `data/skills/` is authoritative and contains 13 Skill domains with localized names, descriptions, UUIDs and review metadata. Preserve all authored IDs and translations.
The existing `data/lessons/` contains editorial lesson and Scene design documents; these Markdown specifications are not executable lessons, and are not fabricated as JSON. Existing locale-coverage and content-type tests remain available.
Existing `docs/` are editorial sources, not application UI.

## Build and publish

From the monorepo root, after `npm ci`:

```bash
npm run package:build --workspace @svitlo/math
npm run code:check:types --workspace @svitlo/math
npm run test:publish --workspace @svitlo/math
npm run test:portability --workspace @svitlo/math
```

The build creates `dist/textbook/index.{js,d.ts}` and `dist/manifest.json`; if authored Skills exist, it uses the existing shared Engine generator to produce localized `dist/static/data/pages/skillAnalytics/<language>.json`. Real lessons, when authored as `*.data.ts`, are generated by the existing shared lesson generator. No fake lessons or Scene Registry is included. A `/scenes` or `/styles` export should be added only after real React DOM Scenes and CSS have been authored.

Consumers import `{ textbook }` from `@svitlo/math` and run:

```bash
svitlo-math publish --output /absolute/path/to/host/public
```

The CLI ships with the npm tarball. It copies **prebuilt** `dist/static` resources, not authoring files, and never regenerates content. Its `.svitlo/publish-math.json` tracks only this textbook's previously published files for safe stale cleanup. Host routes, flags, global localization, native integrations and deployment are owned by `apps/web`, `apps/mobile` and `apps/desktop`.

Mathematics-specific historical Next.js page and locale-router scaffolding is not part of this distribution. Consumer-side navigation and session behavior belongs to the hosts and shared UI packages.
