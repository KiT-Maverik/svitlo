# Language and Literature — Svitlo standalone textbook

Minimal Next.js App Router workspace: `@svitlo/language-literature` in `content/language-literature`.

This scaffold contains no Skills Taxonomy, curriculum, lessons, questions, or assessment data. Future subject content, assets, and tests belong inside this package. Shared code must be consumed through public `@svitlo/*` exports, never another application's sources.

## Commands

From the monorepo root after `npm ci`:

- `npm run dev:language-literature`
- `npm run build:language-literature`
- `npm run typecheck:language-literature`
- `npm run lint --workspace @svitlo/language-literature`
