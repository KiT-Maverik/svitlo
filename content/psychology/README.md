# Psychology — Svitlo standalone textbook

Minimal Next.js App Router workspace: `@svitlo/psychology` in `content/psychology`.

This scaffold contains no Skills Taxonomy, curriculum, lessons, questions, or assessment data. Future subject content, assets, and tests belong inside this package. Shared code must be consumed through public `@svitlo/*` exports, never another application's sources.

## Commands

From the monorepo root after `npm ci`:

- `npm run dev:psychology`
- `npm run build:psychology`
- `npm run typecheck:psychology`
- `npm run lint --workspace @svitlo/psychology`
