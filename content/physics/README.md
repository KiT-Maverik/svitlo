# Physics — Svitlo

Standalone Next.js textbook application scaffold (`@svitlo/physics`) in `content/physics`.

The application is initialized independently of the Physics Skills Taxonomy. The editorial taxonomy and Subject Proposition remain in a separate documentation PR. This scaffold contains no taxonomy, curriculum, lessons, Questions, Skill Data, or runtime Skill registration.

From the monorepo root: `npm run dev:physics`, `npm run build:physics`, `npm run typecheck:physics`.
