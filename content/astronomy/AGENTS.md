# Astronomy textbook package

Follow the repository root `AGENTS.md`, Studio Lesson/Scene workflow, current Engine
contracts and textbook package boundaries. Keep authored `data/` and editorial
`docs/` intact; never fabricate educational content or pretend that generated
Lesson/Scene placeholders are finished resources.

Astronomy now contains reviewed authored Lesson sources and three UUID-addressed
React Scene implementations for `skyChangesOverview` under `scenes/`.
Scene implementations belong to this textbook package; import the selected
localized Scene response, not build-only authoring dictionaries or host providers.
The static lazy registry is generated by `content:generate:scenes` and checked by
`content:check:scenes`; never edit it by hand after a registry change.
Use co-located tests, real a11y/RTL/offline behavior, and exact Scene UUIDs.

This textbook remains a platform-neutral distribution. Host routing, Next.js,
app UI providers, and client cache management do not belong in this package.
`dayScene` photographic evidence and all Scene spoken audio remain explicit
production blockers until real licensed/offline assets and tests exist.
