# Ukrainian — Svitlo standalone language textbook

Minimal Next.js App Router workspace: `@svitlo/ukrainian` in `content/languages/ukrainian`.

This is an empty Ukrainian-language textbook scaffold, with no Skills Taxonomy, curriculum, lessons, questions, or assessments. Authored content and package-owned docs/tests can be added here later. Shared code must use public `@svitlo/*` exports, not another application's source files.

## Commands

From the monorepo root after `npm ci`:

- `npm run dev:ukrainian`
- `npm run build:ukrainian`
- `npm run typecheck:ukrainian`
- `npm run lint --workspace @svitlo/ukrainian`
