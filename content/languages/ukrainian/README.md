# Українська мова — Svitlo textbook package

`@svitlo/ukrainian` is a platform-neutral, compiled ESM textbook package. It does not own Next.js routes or host navigation. `content/playground` defines the canonical package architecture; this package publishes **only** its actual authored content.

## Authoring

There is currently no authored lesson or Skills taxonomy. A metadata-only distribution and an empty static-resource manifest are intentional.

Existing `docs/` are editorial sources, not application UI.

## Build and publish

From the monorepo root, after `npm ci`:

```bash
npm run build --workspace @svitlo/ukrainian
npm run typecheck --workspace @svitlo/ukrainian
npm run test:publish --workspace @svitlo/ukrainian
npm run test:portability --workspace @svitlo/ukrainian
```

The build creates `dist/textbook/index.{js,d.ts}` and `dist/manifest.json`; if authored Skills exist, it uses the existing shared Engine generator to produce localized `dist/static/data/pages/skillAnalytics/<language>.json`. Real lessons, when authored as `*.data.ts`, are generated by the existing shared lesson generator. No fake lessons or Scene Registry is included. A `/scenes` or `/styles` export should be added only after real React DOM Scenes and CSS have been authored.

Consumers import `{ textbook }` from `@svitlo/ukrainian` and run:

```bash
svitlo-ukrainian publish --output /absolute/path/to/host/public
```

The CLI ships with the npm tarball. It copies **prebuilt** `dist/static` resources, not authoring files, and never regenerates content. Its `.svitlo/publish-ukrainian.json` tracks only this textbook's previously published files for safe stale cleanup. Host routes, flags, global localization, native integrations and deployment are owned by `apps/web`, `apps/mobile` and `apps/desktop`.
