# Assessment Workflow

[Create Assessment Flow](./create-assessment-flow.skill.md) is the proposed entity-owned Assessment authoring procedure. It describes distinct methodology, content authoring, independent review, resource materialization, translation and human QA, reusing reviewed upstream Lesson Question Banks and the existing Quiz Section.

Assessment is a direct child of Course, Module or Chapter at an exact ordered placement. The Course Stage 5 placeholder and returned Assessment inventory are **planned behavior**, not an executable production command yet; the direct typed materializer implementation must be reconciled with PR #823. Read the entity [Assessment contract](../../docs/entities/assessment.md) and the [Course workflow](../course-workflow/create-course-flow.skill.md) for responsibility boundaries.
