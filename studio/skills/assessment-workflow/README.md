# Assessment Workflow

[Create Assessment Flow](./create-assessment-flow.skill.md) is the proposed entity-owned Assessment authoring procedure. It describes distinct methodology, content authoring, independent review, resource materialization, translation and human QA, reusing reviewed upstream Lesson Question Banks and the existing Quiz Section.

Course Stage 6 verifies reviewed upstream Lesson-owned Questions. Course **Stage 7 Design Assessments** is the **conditional parent coordination checkpoint**, not a ninth Assessment-owned stage: if the Methodologist's complete, verified Stage 2 Course structure contains **zero Assessment slots**, the parent Course PR marks Stage 7 **Skipped** with source SHA evidence; otherwise it links each actual Assessment slot to its separate eight-stage entity-owned PR and verified Question dependencies. No required/not-required flag or opt-out record is used. Course Stage 8–9 translations do not translate independently owned Assessment content; Course Stage 10 human QA verifies actual integrated Assessment readiness. See the [Course PR tracker template](../course-workflow/create-course-flow.skill.md#canonical-pr-tracker).

Assessment is a direct child of Course, Module or Chapter at an exact ordered placement. PR #826 implements Course Stage 5 blocked inline placeholders, typed seeds and returned Assessment inventory in the actual #823 direct materialization pipeline, plus Zod-authored Assessment Stage 1/2 and a trust-gated source-materialization command. These are **Draft branch implementations**; until Ready checks, default-branch deployment and an authorized real run succeed, do not represent the command, authored output or hosted navigation as proven operational. Read the entity [Assessment contract](../../docs/entities/assessment.md) and the [Course workflow](../course-workflow/create-course-flow.skill.md) for responsibility boundaries.
