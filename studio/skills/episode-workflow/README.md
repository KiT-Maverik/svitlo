# Episode Workflow

[Create Episode Flow](./create-episode-flow.skill.md) defines the ten-stage Course-owned narrative production procedure. The Episode PR is the sole stage tracker. Read the [Episode entity](../../docs/entities/episode.md) and [Course workflow](../course-workflow/create-course-flow.skill.md) before starting.

The Course provides approved placement intent; it does not author Episode dialogue or independently approve Episode locales. The Episode has its own immutable identity and editorial source, not Lesson methodology, Skills or assessment banks. Materialization, resource implementation, localization, human media production and human QA are separate gates.
