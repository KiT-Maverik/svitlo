# Lesson generated source layout

**Current typed source contract.** Lesson authoring progresses in a single UUID-addressed `content/<book>/data/lessons/<bucket>/<lesson-uuid>/draft.ts`, first `LessonWorkflowStage1`, then `LessonWorkflowStage2`. The Stage 2 object is not a `Lesson_Configurator`; it contains plain `{config, production?}` nodes and ordered `items/order` collections.

On an authorized trusted SHA-pinned Stage 6.1 command, the valid `draft.ts` is deleted in the same atomic Git commit that creates the completed source tree. Exact source bytes remain recoverable from the pinned parent commit and blob. The generated canonical `index.ts` contains the `defineLesson` imports and exports, with independently materialized `sections/<slug>/index.ts` and nested Section/Block modules. The **same Section renderer** produces equivalent relative source layouts for Lesson and Episode. Course Stage 5 creates only the minimal new Course-owned `CourseWorkflowLessonSeed` `draft.ts`, not completed Sections. Stage 3 independent review and Stage 4–5 specialist audits remain editorial procedures, not machine-readable materializer gates.

Media and other resource specifications remain colocated with their nested modules. For each Scene, Stage 6.1 simultaneously creates the nested `defineScene` Config and six valid but blocked React Scene draft files under the same textbook's `scenes/<uuid-last-hex>/<uuid>/` directory. The complete reviewed Scene specification is embedded as safe line comments in `SceneName.tsx` rather than emitted as a separate specification file. Stage 6.3 still implements, tests and registers Scenes. Actual media files, banks, approved translations and Props remain independent. Unresolved dependencies are explicit `TODO(asset)`/`TODO (BLOCKER):` and cannot be published. Generated paths are strictly limited to Lesson UUID ownership and the same-textbook Scene UUID allowlist, with six-file completeness, symlink/traversal, collision, stale SHA and no-clobber checks. Deterministic IDs remain persisted in source.

See the real source emitters in `shared/engine/generators/materializers/lesson/`, the trusted command in `scripts/ci/lessonMaterialization/`, and [Create Lesson Flow](../../skills/lesson-workflow/create-lesson-flow.skill.md) for Stage 6.2/6.3 acceptance.

Its generated source snapshots and builder files were retired in #797 and are recoverable from Git history; do not reintroduce a YAML authoring pipeline or infer present behavior from those old examples.
