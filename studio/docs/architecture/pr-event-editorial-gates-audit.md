## Evidence consumers and decisions

- **Removed editorial parser:** Course, Episode and Bank materialization no longer parses PR description review evidence; the obsolete shared parser and its tests are removed. All five commands use authorized invocation, valid pinned typed source and real technical ownership/transaction checks.
- **Removed Bank editorial metadata:** entity markers, checklist stages, parent PR prose and Questions Completed/N/A review verdicts are not eligibility inputs. The canonical path and current base identify the bank and its owning Lesson; actual typed source/reference and publication checks remain. Questions-first remains editorial guidance.
- **Needed post-commit reconciliation:** Course materialization's `reconcile-pr-tables` job reads/writes managed Lessons/Episodes blocks in the Course description only after verifying the committed manifest and digest. This is a metadata publisher, not a pre-materialization editorial authorization gate; preserve atomic-source and race protections.
- **Removed by #812:** Lesson source materialization no longer relies on PR prose/stage-review/parent provenance parsing. The same source-first boundary now applies to every entity.
- **Needed input:** `pr-labeler.yml` reads the PR title to apply `pr: integration`. It does not need body edits. The remaining comment routers read exact command strings and validate actor/PR/source metadata.
- **Not observed in workflow triggers:** Other workflows do not declare `edited`. Avoid broadening their triggers or enabling Draft heavyweight validation to fix this issue.
