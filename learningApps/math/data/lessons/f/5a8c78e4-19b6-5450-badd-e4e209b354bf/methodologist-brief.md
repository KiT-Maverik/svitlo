# Which One Is Third? Position Depends on the Start — Methodologist Brief

## Educational purpose

Recognize the ordinal position of an object in an explicitly directed sequence; distinguish its rank from the number of objects and show that changing origin or order changes rank but not total.

## Target audience

**Primary grade: Grade 1.** This selection depends on mathematical complexity, prerequisites and developmental readiness, not a grade label embedded in Skill Taxonomy. Early readers can use short instructions, countable models and ordered text alternatives.

## Prerequisites

One-to-one correspondence and cardinal counting through six; first through sixth introduced with oral and text support. The learner can track a named starting point.

## Target Skills

- [basicOrdinal.data.ts](../../../../data/skills/counting/ordinal/skills/basicOrdinal.data.ts)

## Expected learning outcomes

- C is third; six bags total.
- C is fourth; still six bags.
- Star is fifth; five items remain.
- S is fourth; total five.
- Explain a changed-context instance using evidence rather than repeating a memorized answer; formative success is not proof of verified mastery.

## Essential subject matter

For A,B,C,D,E,F counted from A, C is third; counted from F, C is fourth. The total remains six in both cases. Swapping Star and Rain in Sun,Moon,Star,Cloud,Rain makes Star fifth while total stays five. Ordinal position is relative to an order and its starting direction.

## Conceptual progression and dependencies

Introduce prerequisite number and object meanings → construct and inspect the first model → explain its contrast → retrieve the mathematical principle → independently apply it in the second Scene with a changed arrangement or representation.

## Misconceptions, examples and boundaries

Confusing third with a collection of three; assuming leftmost means first regardless of START; believing an item stays third when its place changes; believing a swap adds an item.

**Instructional depth and hard exclusions:** Grade 1: five or six identifiable items and explicit START marker; no number-line lengths, sorting magnitude, ordinal spelling drills, speed tests or grades.

**Verified numerical examples:**

- C third from A; six in total.
- C fourth from F; six in total.
- Star third becomes fifth, total five.
- S fourth from entrance; five cushions.
