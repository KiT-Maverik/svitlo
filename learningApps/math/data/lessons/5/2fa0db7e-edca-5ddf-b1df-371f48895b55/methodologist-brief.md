## Educational purpose

Classify specified events as certain, impossible or possible-but-not-certain using all possible outcomes of a one-token draw. The intended conceptual change is from judging by appearance or one tempting example to checking the specific mathematical condition. This lesson serves one independently assessable canonical Skill without altering its identity.

## Target audience

**Primary grade: Grade 2**, approximately ages 7–8. Learners can distinguish must/cannot/might in a fully specified experiment before calculating numerical probabilities; 'possible' is not assumed to mean half-and-half. Assume mixed literacy and language fluency: child-facing phrasing must be short and supported by visible and nonvisual equivalents.

## Prerequisites

- Understand selecting one token without seeing it.
- Read or identify blue and red object labels.
- Differentiate the everyday meanings of 'must', 'cannot' and 'might'.

Prerequisite competence is a planning assumption, not evidence of mastery. A learner lacking it needs a separate scaffold, not a new definition of the target Skill.

## Expected learning outcomes

- State the possible colors for one draw from a completely specified bag.
- Identify a green draw as impossible if the bag contains no green tokens.
- Identify drawing blue-or-red as certain when those are the only colors present.
- Explain why drawing one red token from two blue and one red tokens is possible but not certain.
- Reevaluate all claims after changing the bag contents.

Completing an exploratory interaction is not independent validation of mastery. Any later formal evidence or scoring belongs to an assessment design.

## Essential subject matter and instructional depth

Finite one-draw sample spaces with visible, fully specified bag contents; event categories based on all/some/no available outcomes. No percentages, numeric probabilities, independence, streak predictions or fairness assumptions.

Canonical certainImpossible Skill defines certain as including all outcomes and impossible as including none; events that can occur need not have 50% probability.

## Conceptual progression and dependencies

Start from the listed prerequisites, identify what information determines the answer, make a prediction, reveal a controlling comparison, and explain it before transfer. Use a closed conceptual bag with a completely disclosed inventory before predictions: two blue tokens and one red token. 'Green' is never among the disclosed outcomes. Repeated draws are not required and must not be used to imply guarantees. Conceptual depth is set for this lesson's grade only; the Skill taxonomy remains grade-independent.

## Misconceptions, examples and boundaries

- Anything possible is automatically 50/50.
- A rare event cannot happen.
- If an event is possible, it must happen on the next draw.
- Changing the sample space does not change what is certain or impossible.

Concrete boundaries: Finite one-draw sample spaces with visible, fully specified bag contents; event categories based on all/some/no available outcomes. No percentages, numeric probabilities, independence, streak predictions or fairness assumptions. Repeated exposure alone must not be presented as mastery.
