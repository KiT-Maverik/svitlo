## Educational purpose

Match exactly one spoken count word to each new object, without skipping or recounting. Program-neutral and independently teachable.

## Target audience

**Grade 1 (primary audience)**, early readers using short prompts, countable illustrations, and optional narration. No requirement for mouse use, hearing, or fluent reading.

## Prerequisites

Know the spoken number words one to five; point to distinct objects. Provide an optional introductory reminder, not an assumption of demonstrated mastery.

## Target Skills

- [oneToOne.data.ts](../../../../data/skills/counting/sequence/skills/oneToOne.data.ts)

## Expected learning outcomes

1. The sixth different button corresponds to the word six.
2. Any order counts the same seven distinct objects.
3. One unmarked stone means the count is incomplete; the final total is six.
4. Nine different marks correspond to nine count words, without repetition.

- Explain a new instance using the underlying number relationship, not merely identify a familiar arrangement.

## Essential subject matter and instructional depth

1–10 concrete objects; no digit-writing, time pressure or formal arithmetic. Verified model examples:

- Six buttons, six distinct count words.
- Seven pebbles stay seven when scattered.
- Five marked plus one unmarked = six stones.
- There are nine stones; each received one word.

## Conceptual progression and dependencies

1. Six buttons in a tray: Mark each of six separated buttons; each advances a count-word ledger once.
2. Scattered pebbles: Rearrange seven pebbles, then count by choosing a new unmarked pebble in any order.
3. Find the missing stone: Show six stones with only five counted; let learner identify the missed item and complete a new count.
4. Path of nine stones: Independently count nine stones in a new path layout; allow ordered list navigation without tapping stones.

## Misconceptions, examples and boundaries

Repeating a word for one item, omitting obscured objects, double-counting an already marked object. Feedback must point to the relevant concrete counting evidence. No score, timed drill, or inference of mastered competence.
