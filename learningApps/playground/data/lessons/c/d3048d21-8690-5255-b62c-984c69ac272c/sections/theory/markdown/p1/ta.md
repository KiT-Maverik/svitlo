# ஒளி எவ்வாறு பரவுகிறது

சூரியக் கதிருக்கும் மின்விளக்கின் ஒளிக்கும் என்ன ஒற்றுமை? **ஒளி** எவ்வாறு பரவுகிறது என்பதைப் புரிந்துகொள்ள இரண்டும் உதவுகின்றன.

## மூலத்திலிருந்து பொருளுக்கு

ஒளி புகும் சீரான ஊடகத்தில் ஒளி நேர்கோட்டில் செல்கிறது. அதன் திசையை அம்புக்குறி கொண்ட கோடான **ஒளிக்கதிர்** மூலம் காட்டுகிறோம்.
